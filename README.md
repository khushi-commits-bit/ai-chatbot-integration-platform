# 🤖 AI ChatBot Integration Platform

A modern, responsive dashboard built with React to manage and monitor AI chatbot integrations across different platforms.

## 📌 About the Project

The **AI ChatBot Integration Platform** is a frontend web application designed to provide a central dashboard for managing chatbot integrations. It presents chatbot information, summary statistics, and platform filtering in a clean, user-friendly interface.

This project is being developed as part of a software project to explore React development and chatbot management interfaces.

## ✨ Features

- **Dashboard Overview** — Displays summary statistics and chatbot information.
- **Chatbot Management Interface** — Shows chatbot details in an organized table.
- **Platform Filtering** — Filter the displayed chatbots by platform.
- **Responsive Design** — Layout adapts to different screen sizes.
- **Modern User Interface** — Clean styling with sidebar navigation and dashboard cards.

> **Note:** This is currently a frontend prototype using sample data. Backend integration, persistent chatbot management, and live AI services are not yet implemented.

## 🛠️ Technologies Used

- **React** — Building the user interface.
- **Vite** — Development server and build tool.
- **JavaScript** — Application logic.
- **CSS** — Styling and responsive layout.
- **Git and GitHub** — Version control and project hosting.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### Prerequisites

Install the following:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/)

### Installation

**1. Clone the repository**

Replace `YOUR-USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR-USERNAME/ai-chatbot-integration-platform.git
```

**2. Open the project folder**

```bash
cd ai-chatbot-integration-platform
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

If you use Windows PowerShell and encounter an npm script execution-policy error, try:

```powershell
npm.cmd run dev
```

**5. Open the application**

Open the local URL displayed in your terminal, usually:

`http://localhost:5173/`
